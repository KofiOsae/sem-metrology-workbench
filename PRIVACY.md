# Privacy

SEM Metrology Workbench 1.2.1 is available as offline desktop software and an
optional hosted browser edition.

- The offline desktop application transmits no images, measurements, filenames,
  instrument metadata or usage events.
- No account is required.
- Exported reports remain in locations selected by the operator.
- Process-study JSON files can contain local paths and sample labels; review
  them before sharing.
- Traceability JSON files contain the source filename and its SHA-256 identity,
  but not the source pixels.
- Privacy-safe support ZIP files omit the original acquisition. Their optional
  reviewed overlay can still show raster labels or specimen information and
  must be inspected before sharing.

Project maintainers may use aggregate GitHub repository traffic (14-day views,
visitors and clones) and aggregate GitHub Release asset download counts. These
statistics are provided by GitHub and are not generated by the application.

## Hosted browser edition

- The selected SEM image is transmitted over HTTPS to the Render web service
  because the metrology engine runs on the server.
- The application processes the request in memory and does not intentionally
  store the image, filename or result in a database or persistent disk.
- No account is required. The browser edition stores a random installation ID
  in the browser and sends it only after a completed analysis. The server stores
  a one-way hash of that ID, recipe name, app version and completion time so the
  public aggregate can report completed analyses and distinct installations.
- Failed and cancelled analyses are not counted. The application usage table
  does not store images, filenames, measurements, calibration, IP addresses or
  user-agent strings. Only aggregate totals are exposed publicly.
- Hosting-provider request and infrastructure logs may still contain ordinary
  network metadata such as time, IP address and user agent according to the
  provider's policies; they do not need the SEM pixel data for application
  logging.
- Do not submit confidential, personal, proprietary or export-controlled data.
  Use the offline desktop edition for those acquisitions.
