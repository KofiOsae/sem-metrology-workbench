SEM Metrology Workbench 1.2.0

Research software. Review calibration, physical recipe, overlays and QA. SEM grayscale is not calibrated surface height.

Laptop workspace

The numbered three-column workflow places collapsible settings on the left, the calibrated image and dropdown-selected results in the centre, and release/model diagnostics on the right. Drag the dividers or use the toolbar width sliders; Reset widths restores a balanced layout. Proportions are remembered.

Fast start

  1. Open the original SEM acquisition.
  2. Verify the magenta scale endpoints and printed value. If wrong, use Redraw scale-bar endpoints, then confirm calibration.
  3. Select the physical recipe and credible size limits.
  4. Optionally teach one complete isolated reference feature and select/mask the analysis region.
  5. Run analysis and inspect the overlay before accepting tables.
  6. Inspect statistics and hover individual plot points.
  7. Export CSV, plot PNG or the selectable professional PDF.

Calibration tutorial

Companion pixel-size metadata is preferred. An automatically found raster bar is only a proposal. Endpoint dots must lie on the physical endpoints—not text, an entire footer baseline or extra ticks. Manual endpoints use original-image pixels and are recorded as operator-drawn.

Irregular particles

Teach one complete isolated particle. Magenta isolated contours support primary statistics. Orange touching/watershed contours describe visible segments only and remain REVIEW; hidden overlap boundaries cannot be reconstructed from one projection.

Cross-sections

For each feature, draw a ROI containing complete top, both sidewalls and local substrate. The green height gauge identifies the datum. Repeat for multiple structures. In layer mode, I1/I2… correspond to layers L1=I1–I2; remove false cyan candidates by ID.

Line profile

Draw through representative particle centers. Results are calibrated lateral FWHM-like chords, gaps and center spacing plus intensity. An off-center chord is smaller than diameter. Intensity is not height.

Statistics and traceability

N is always shown. Std describes feature dispersion; standard error and mean 95% CI describe the sample mean and are not a complete uncertainty budget. Investigate multimodality/outliers physically rather than deleting points to improve CV. CSV export creates an image-checksummed JSON traceability sidecar. The privacy-safe support ZIP omits the original acquisition but can include the reviewed overlay; inspect it before sharing.

Process/dose studies

Use a consistent recipe and acquisition practice. Add each reviewed image with a trusted process factor and replicate. Each plotted point is an image; error bars are within-image Std. Dose is never inferred from pixels.

Troubleshooting

Wrong dimensions

Correct scale endpoints/value/unit and rerun. Prefer raw data and calibrated references.

Too few/many objects

Check recipe, polarity, tight reference, credible size bounds, masks, border rejection and image quality. Review boundaries, not only counts.

Implausible cross-section height

Tighten the ROI around one structure and confirm the green top/substrate gauge.

Cannot edit layers

Run layer analysis, select interface ID, then remove it; or activate click-to-remove and click inside the yellow ROI.

App will not start

Use the official x64 release, verify SHA-256, copy to a writable local folder, and report Windows version plus exact error.

Citation, privacy and support

Cite the exact version using CITATION.cff and the Zenodo DOI when available. The app sends no telemetry or images. Share de-identified data only. Full Markdown manuals, validation references and issue-reporting instructions ship with the source repository.
