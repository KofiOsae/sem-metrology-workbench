- [x] Add the final public repository URL to `CITATION.cff`.
- [x] Confirm copyright holder/contributor names.
- [ ] Run all unit/synthetic tests.
- [ ] Perform manual trials for every capability-matrix row.
- [ ] Review third-party licenses and include required texts.
- [ ] Build only the canonical single-file Windows executable.
- [ ] Smoke-test on a clean supported Windows x64 machine.
- [ ] Virus/malware scan and preferably code-sign the executable.
- [ ] Publish SHA-256 and release notes.
- [ ] Create public GitHub repository and tag `v1.0.0`.
- [ ] Upload executable and checksum as GitHub Release assets.
- [ ] Enable Zenodo GitHub integration and archive the release.
- [ ] Update `CITATION.cff` with the Zenodo DOI in a patch release if necessary.
- [ ] Enable GitHub Discussions/Issues and private vulnerability reporting.
- [ ] Review aggregate Insights and release downloads; no app telemetry.
