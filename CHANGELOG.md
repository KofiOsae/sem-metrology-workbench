# Changelog

## 1.2.0 — 2026-11-05

- Numbered settings, visualization/results and diagnostics workflow columns.
- Direct settings/diagnostics width sliders plus one-click width reset.
- Separate collapsible release, model-compatibility and operator-guidance panels.
- Retains the compact selectable centre result view and saved splitter layout.

## 1.1.0 — 2026-11-05

- Laptop-first three-column workspace with settings, visualization/results and diagnostics.
- Collapsible settings and guidance sections reduce vertical scrolling.
- Centre-view selector switches measurements, statistics, plots and QA without wide tabs.
- Adjustable horizontal and vertical splitters retain their proportions between sessions.
- Compact toolbar and two-row summary cards preserve analysis space on smaller screens.
- GitHub Actions updated to current supported checkout and Python setup actions.

## 1.0.0 — 2026-11-04

- Native standalone Windows metrology workbench.
- Eight physical measurement recipes plus line gauge and signal-texture tools.
- Operator-correctable calibration and traceable QA states.
- Class-aware and contact-aware statistics and interactive distributions.
- Cross-section populations, layer-interface review and process/dose studies.
- CSV, PNG and selectable professional PDF reporting.
- Bundled tutorial, troubleshooting, citation, privacy and validation material.
