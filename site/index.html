A reviewable measurement workflow

01

Open and calibrate

Load the original acquisition. Confirm companion metadata or the physical scale-bar endpoints and value.

02

Select the physical model

Choose the recipe that matches the fabricated geometry. Optionally teach one complete reference feature.

03

Review the overlay

Check every detected contour, datum, interface and rejection—not only the reported count.

04

Release evidence

Inspect statistics, distributions and QA, then export PDF, CSV, PNG or a traceability record.

Structure-aware outputs

Circles, rings and holes

Diameter, lattice periods, edge roughness and multiple size populations.

Rectangular arrays

Length, width, X/Y periods and edge roughness.

Irregular particles

Isolated/contact-aware Feret, equivalent diameter, area and shape statistics.

Line-space gratings

Critical dimension, pitch, duty cycle, LER and LWR.

Cross-sections and films

Feature height, CDs, sidewall angle and reviewed layer-stack thicknesses.

Single features and waveguides

Contour descriptors, path length, local normal width and taper.

Line profiles and signal texture

Calibrated lateral chords, gaps, spacing and clearly labelled SEM-signal Ra/Sa descriptors.

Process studies

Compare reviewed image-level measurements against dose, focus, time or another trusted factor.

Choose your privacy mode

Offline for sensitive work; browser for accessible trials.

The desktop application sends no telemetry and uploads no images or results. The hosted browser edition necessarily transmits the selected image to Render for in-memory analysis and does not intentionally persist it.

Do not upload confidential, personal, proprietary or export-controlled acquisitions. Usage is assessed only through aggregate repository traffic and release-download counts.
